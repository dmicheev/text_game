# Admin-Dashboard Specification

## Purpose

Панель управления ведущего внутри Telegram: самообновляющееся сообщение
со статусом игры и ручными действиями. Отдельный веб-интерфейс в MVP не делается.

## Requirements

### Requirement: Живой дашборд игры

**User Story:** Как ведущий, я хочу видеть актуальный статус партии
и вмешиваться, если игрок пропал.

#### Acceptance Criteria

1. WHEN /admin THEN система SHALL показать список активных игр ведущего
   (все игры — если пользователь глобальный админ)
2. Для каждой игры SHALL существовать одно дашборд-сообщение в чате
   ведущего, редактируемое при каждом событии игры (ход, пропуск, пауза)
3. Дашборд SHALL показывать: статус, главу N/M, текущего автора и время
   молчания, очередь игроков
4. Дашборд SHALL иметь кнопки: [Напомнить] [Передать ход] [Пауза/Продолжить]
   [Отменить игру]
5. «Передать ход» и «Отменить» SHALL требовать подтверждения вторым нажатием
6. WHEN игра создаётся THEN система SHALL отправить дашборд ведущему
   автоматически

#### Scenario: Ручная передача хода

1. Ведущий открывает /admin, выбирает игру
2. Нажимает «Передать ход», подтверждает
3. Вызывается тот же skip_turn, что и по таймауту
4. Дашборд обновляется, следующий игрок получает ход

#### Scenario: Пауза

1. Ведущий нажимает «Пауза»
2. Игра переходит в PAUSED, таймеры замораживаются
3. «Продолжить» сдвигает дедлайн на длительность паузы
