# User-Registration Specification

## Purpose

Регистрация игроков у бота: без /start бот не может инициировать диалог,
поэтому каждый участник обязан зарегистрироваться до включения в игру.

## Requirements

### Requirement: Регистрация через /start

**User Story:** Как игрок, я хочу зарегистрироваться у бота одной командой,
чтобы ведущий мог добавить меня в игру.

#### Acceptance Criteria

1. WHEN пользователь отправляет /start THEN система SHALL создать запись
   в users (tg_id, username, имя) если её нет, и ответить приветствием
2. WHEN существующий пользователь отправляет /start THEN система SHALL
   обновить его username/имя и НЕ создавать дубликат
3. WHEN команда /whoami THEN система SHALL показать профиль пользователя

#### Scenario: Новый игрок

1. Пользователь отправляет /start
2. Бот создаёт запись в БД
3. Бот отвечает приветствием с кратким описанием игры

#### Scenario: Повторный /start

1. Зарегистрированный пользователь отправляет /start
2. Бот обновляет устаревший username
3. Бот отвечает тем же приветствием без дублирования записи
